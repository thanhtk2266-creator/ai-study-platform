# AI Study Platform

AI-powered learning platform that generates multiple-choice quizzes
from uploaded study materials such as PDF and PowerPoint files.

## Features

- Upload PDF / PowerPoint documents
- AI-generated multiple-choice questions
- Quiz scoring
- Answer explanations
- RAG-based question generation
- Semantic search using vector database

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python
- LangChain

### AI / RAG
- LLM
- Embedding Model
- Vector Database

### Database
- PostgreSQL
- Vector Database
